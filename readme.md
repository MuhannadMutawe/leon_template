# 🚀 Leon - Responsive Landing Page

A modern, clean, and fully responsive landing page built using **HTML5** and **CSS3**.  
This project showcases a minimal agency website with smooth layout, responsive design, and reusable UI sections.

---

- 🎨 Modern & Clean UI
- 📱 Fully Responsive Design
- ⚡ Lightweight & Fast
- 🧩 Well-Organized Code Structure
- 🌐 Cross-Browser Compatible
- 🎯 Semantic HTML5
- 🎭 Font Awesome Icons
- 🔤 Google Fonts Integration

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/yourusername/leon-template.git
```

2. Navigate to the project folder

```bash
cd leon-template
```

3. Open `index.html` in your browser.

No installation or dependencies are required.
